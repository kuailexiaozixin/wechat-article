# A5 行文工艺：研究性专业文章的写法

A5 把 A1-A4 的四张清单变成 `draft.md`。前四步决定文章站不站得住，这一步决定它读不读得下去。

读者是同行——财会人员、税务干部、律师、投行与研究员、监管人员。他们的阅读习惯跟大众读者不同：**先看结论，再看依据，随时准备反驳**。所以本文只写三件事：怎么让判断准确、怎么让句子站得住、怎么让同行愿意读下去。

配套工具在 A5 的两个同伴文档：`revision-protocol.md`（成稿禁令与七遍改稿）、`de-ai-playbook.md`（去 AI 味操作手册）。机器检查：

```bash

python Write/references/a5-draft/scripts/check_duplicates.py <成品目录> --min-len 40 --threshold 0.8
```

## 一、说话位置：写作者是谁

研究性专业文章只有一个合法的说话位置：**认真把规则和材料读完了的人**。不是亲历者，不是当事人，不是给建议的顾问。

**四种说话位置都合法**，但要分清：

| 位置 | 怎么写 | 红线 |
|---|---|---|
| 亲历（经手过的项目） | 「去年做的两个项目，卡住的地方都在资本化起点的认定」 | 没做过就不能写「我经手过」 |
| 做过调查（访谈、核查、比对） | 「把能找到的准则、解释、案例比了一遍，分歧在第三款」 | 不能把查资料写成亲历 |
| 熟悉行业 | 「这类交易常见的做法有三种，差异在收入确认时点」 | 不能把一家之见写成行业通例 |
| 认真查完资料后形成判断 | 「按现行条文，宜按阶段划分处理」 | 不能把推断写成条文要求 |

**不能把推测写成内幕，不能把一家之见写成共识**。第一人称表达判断不等于伪造经历——"我倾向于认为…"是合法的，"我参与过某上市公司的这项处理"而没有真事，是伪造。

最有价值的部分是**知识的来路**：哪份文件让你发现这个问题、起初怎么理解、后来被哪条材料纠正、哪个细节只有实际做过的人才会注意、两份资料互相矛盾时你怎么取舍。每篇挑一两处自然出现，全都写会变成新的模板。

## 二、句子：主干早点来

中文的力气在动词和主语上。修饰语一多，读者就得先扒开一层才能看到"谁做了什么"。

**反例** → **改法**：

> 在经历了准则多次修订且实务口径始终未能统一的反复尝试以后，最终促使企业改变处理方式的，是一次来自监管的问询。
>
> → 准则改了几次，实务口径一直没统一。后来一家企业被监管问询，才换了做法。

三条具体做法：

1. **先说人做了什么**，再补原因、时间、条件和例子。一句话里出现三四个"的"，先把做事的人提到前面。
2. **顺手接话**：一个动作带出新东西，下一句接着讲这件东西；结果出现，下一句讲谁受影响。指向清楚时省去重复的主语；同时出现两个以上主体、省略会认错人时，把名字写回来。
3. **动词别名词化**：「对处理方式进行了调整」→「改了口径」；「实现了收入的增长」→「多确认了多少收入」。

## 三、段落：一段只办一件事

- 新段落必须带来**新事实、新条文、新案例、新区别或新后果**。同一个观点换套说法不算推进。
- 段落长度拉开：可以有一段很长（讲一个完整的交易链），也可以有两三句就断（一个判断落下就走）。
- 单句成段要有停顿价值，不能连排成口号。
- 同一个关键词可以重复。为躲重复频繁换同义词，在专业文章里是致命的——"开发支出"换成"开发费用"，读者会以为是两笔钱。

**注水检测**：删掉三分之一，事实、条文、判断和阅读体验几乎没变 → 保留删短版。这是 A5 最有效的单项动作。

**具体细节必须有工作**：一笔金额说明风险量级，一段原话说明关系，一次失败说明旧做法为何行不通。装饰性细节（凌晨三点、第三杯咖啡、窗外的雨）没有来源也没改变后文，全部不要。专业文章里的装饰性细节是「某大型集构」「某知名企业」这类模糊到无法核对的指称。

**按局部问题推进**：A2 定了章节顺序，但每一节内部怎么写，仍然按「读者现在最想知道什么」往前走。常见接力：先讲发生了什么→为什么；先给判断→凭什么；先讲通常做法→这次哪里特殊；先讲结果→中间出了什么岔子。

**知识等问题走到那里再出现**。一段背景能解释为什么只能这么处理、改变风险大小、推翻直觉或让结果可懂，就放进来；只证明你读过很多文件，删掉。长文可以绕出去，回来时要多带一件东西（证据、尺度、反例或一次自我修正）。

## 四、条文与依据怎么写

研究性文章的功夫在引用，这里出错最伤。

| 做法 | 说明 |
|---|---|
| 引原文，标明出处 | 「《企业会计准则第 6 号——无形资产》第八条规定：研究阶段的支出，于发生时计入当期损益。」条款号必须写，写到"第几条"而不是"相关规定" |
| 引述要与原文可对照 | 摘录几句关键的，不要转述成自己的话再打引号。改动原文要明确写"概括来说" |
| 效力层级要分清 | 法律 > 行政法规 > 部门规章 > 规范性文件 > 解释与问答 > 地方口径。用低位阶文件推出高位阶结论，是硬伤 |
| 时间效力要写 | 条款何时生效、是否溯及、有无过渡安排。涉及税率、扣除标准、报送期限的，写清适用期间 |
| 冲突要摆明 | 两份文件口径不同时，写清各自说什么、为什么冲突、你的取舍理由。回避冲突比写错更减分 |
| 案例要说理 | 引判决不只看结论，要看它凭什么判。同案不同判时把分歧点写出来 |

数字的写法：核对**时间、单位、样本、口径**四件事；百分比与百分点分开；一个数字后面要说它让谁多花多少钱、多承担多少风险，否则只是装饰。

**来源冲突**时不能挑最适合故事的那一条：写清分歧双方各自主张什么、依据是什么、你为什么更信其中一条。两条都不足以定论时，写成「存疑」，不要硬选。

**核验笔记不要漏进正文**。「公开资料显示」「目前无法确认」「据笔者核查」连续出现，说明你没把后台笔记收拾干净；正文只保留读者需要的归属。

## 五、结论的强度分级

专业文章里，"应当"和"可以"是两个世界的判断。写错一个词，读者会照着你说的做。

| 强度 | 用词 | 什么时候用 |
|---|---|---|
| 强制 | 应当、必须、不得 | 规则明文规定，没有裁量空间 |
| 允许 | 可以、有权 | 规则给留了选择，或明确授权 |
| 建议 | 宜、建议、较为稳妥 | 规则没规定但实务有更优做法 |
| 倾向 | 倾向于、似应、笔者以为 | 有依据但不唯一，存在不同理解 |
| 存疑 | 存疑、有待明确、暂无依据 | 现有材料不足以判断 |

三条纪律：

1. **强度不能超过依据**。只有规范性文件、没有法律条文时，写"宜"不写"应当"。
2. **一条判断只用一个强度**。同一段里"应当…可以…建议…"混着来，读者不知道哪句是硬的。
3. **边界说明一次就够**。每句都加"可能""通常""原则上"，作者就不见了——读者反而不知道该信哪句。

## 六、专业文章也要有边界表述

三样必须写，位置在结论附近或文末：

- **适用范围**：哪些主体、哪些交易形态、哪个期间。研究性文章的结论没有普适性，写清楚才不会误导。
- **例外情形**：哪些情况不适用、哪些需要另行判断。
- **不确定性**：哪些点现有依据不足、只能给倾向性意见、哪些要等进一步明确。

如果文章讨论的是**具体个案的处理**，末尾要有一句"以上为一般性分析，不构成针对具体交易的法律/税务意见"。这不是免责话术，是专业写作的分际——个案结论要看到完整事实才能下。

## 七、过渡：靠内容交接，不靠路标

章节之间、段落之间的过渡，研究性文章最容易被读者察觉。没有交接，读起来就是一叠互不相干的笔记。

- **每节开头接住上一节的结论**，接不住就补一句过渡，或者把这一节挪走。
- 上一节讲完"阶段划分"，下一节直接问"划完阶段，资本化条件怎么判"。这就是交接。
- **不用路标词**。"首先/其次/最后""综上所述""由此可见""值得注意的是"是模型腔，`check_prose.py` 会报。它们的作用本来可以由内容接力完成。
- 中段与结尾至少回扣一次核心问题，把读者拉回主线（A2 的 `relations` 里那条"回扣主线"就是它）。

## 八、标题

- 主标题：写**研究对象 + 判断**，例如「研发过程形成产品对外销售：按阶段划分结转」。冒号和破折号按 `check_prose.py` 的禁令处理（禁破折号，冒号只允许引出原话），所以优先用副标题或分句形式。
- 小标题：写**内容本身**——「资本化条件在实务里怎么判」，不写"抽丝剥茧之道""化繁为简的艺术"。对仗小标题在专业文章里等于告诉读者这节没有实质内容。
- 小标题只在篇幅长到需要定位时用。三千字以内的文章，三到五个小标题足够。

## 八·五、中文韵律的六条可量化做法

研究性文章的句子容易变成「长定语 + 名词」的堆叠。下面六条按数量处理，改完立刻能感觉到差别。

1. **句长不能太齐**。段落内句子长度都差不多时，挑一句压到 10 字以内，或放开一句超过 30 字。整齐的节奏是模型腔最明显的指纹。
2. **连词减半**。「因为/所以/但是/同时/此外/然而」删掉一半，读不断的地方不用补。
3. **名词化还原成动词**。「对处理方式进行了调整」→「改了口径」；「实现了收入的增长」→「多确认了多少收入」。
4. **主干早点来**。一句话有三四个「的」，先找做事的人放到前面。
5. **单双音节按场合选**（买/购买、看/观察）。不整篇换长词，也不强压成单字。同一关键词该重复就重复，为躲重复频繁换同义词会让读者以为是两回事。
6. **停顿有轻重**。多数段落两三句话，允许有一段很长；单句成段要有停顿价值，不能连排成口号。

**留白**：事实、条文、数字前后变化已经说清时，不紧跟一句解释。留白只省读者自己能得到的，关键事实、因果、判断强度和适用条件仍要说清。

**判断要带来路**：敢下判断，就让读者看到判断从哪里来。材料支持七成，就说到七成；不要先摆一个笨答案再宣布看到了更深层。

## 八·六、体裁纪律（六条底线）

1. **一篇一个主题**。核心问题只有一个（A1 的 `question`），结论只有一个（`claim`）。跨两个问题就拆两篇。
2. **系列文章每篇能独立阅读**。不依赖上一篇的中间结论；术语在本篇内解释一次。
3. **中文简体，面向同行但不假设共识**。专业名词首次出现给出解释；同一概念全篇一个写法（A4 的 `terms` 钉住）。
4. **示例数据必须标注**。教学、演示、模拟的金额与编号，正文里明确写「教学示例」「演示数据」「合成数据」。真实数据要能指回来源。
5. **不虚构场景、不虚构数据、不虚构条文**。写不出来源的段落，改成「不知道」或删掉，不用形容词填空。
6. **推送参数不在 A 轨定**。`--title` / `--digest` / `--cover` / 作者环境变量 `WECHAT_AUTHOR` 的上限与取值口径统一见 `Write/references/b4-push/draft-push-parameters.md`；A5 只负责标题与摘要的**内容侧写法**（见第八节）。

## 九、交稿

- 用户只要成稿，就只交成稿。不展示 A1-A4 的 JSON、不展示检查过程、不解释方法论。
- 文末来源：全靠公开材料的文章，列对结论重要的少数来源（三五条），按效力层级排。个人判断为主的文章不附。
- 引用他人观点要标明；转述与直引分开。

- `python Write/references/a5-draft/scripts/check_prose.py draft.md` 硬禁令清零（退出码 0）。
- `python Write/references/a5-draft/scripts/check_duplicates.py <成品目录>` 对系列文章无重复段落。
- 走完 `revision-protocol.md` 的七遍改稿与冷读。
- `logic.json` 的 `statements` 与实际成稿一致（成稿改动了主题句或结论句，回 A4 同步）。
